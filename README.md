# 🧱 Ball Smasher

Ball Smasher is a simple arcade-style game inspired by classic brick-breaking games. The player controls a paddle to keep the ball from falling into the void while using the ball to destroy all the bricks.

## 🎮 Gameplay

The goal is simple:

- 🏓 Control the paddle to bounce the ball.
- ⚽ Keep the ball from falling into the void.
- 🧱 Use the ball to hit and destroy the bricks.
- 🏆 Destroy all the bricks to complete the level.

## ✨ Features

- Ball and paddle physics
- Brick destruction system
- Collision-based gameplay
- Game-over condition
- Level completion system
- Simple arcade-style gameplay

## 🛠️ Built With

- **Unity**
- **C#**
- Unity Physics & Collision System

## 🎯 Objective

**Keep the ball alive, destroy every brick, and complete the level!**

## 📂 Project Status

This is a gameplay prototype created to practice Unity game development, physics, collision detection, and basic game mechanics.
